KIRA SPARKLES WORDPRESS THEME

Before activating, copy these from your original website folder (C:\xampp\htdocs\kirasparkles) into this theme folder:
  1. css\styles.css            -> css\styles.css
  2. js\script.js              -> js\script.js
  3. everything in assets\     -> assets\   (logo.svg, icon-*.svg, map-illustration.svg ...)
     (do not worry about overwriting: the pictures in this theme have different names)

Then in WordPress: Appearance > Themes > Kira Sparkles > Activate.
Activation creates the Home, About Us, Services, Gallery and Contact Us pages and the main menu.
